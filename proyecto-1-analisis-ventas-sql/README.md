# 📊 Análisis de Ventas y Comportamiento de Clientes (SQL)

## 📌 Descripción
Proyecto enfocado en la extracción, cruce y análisis de datos transaccionales mediante SQL para responder preguntas clave de negocio sobre el rendimiento de las ventas y el valor del cliente.

## 🛠️ Habilidades Técnicas Demostradas
* Diseño y modelado relacional de bases de datos.
* Cruces de tablas con `INNER JOIN` y `LEFT JOIN`.
* Agregación de datos con `GROUP BY`, `SUM()`, `COUNT()` y filtros con `HAVING`.
* Ordenamiento e identificación de clientes de mayor valor.

## 📂 Archivos del proyecto
* `01_esquema_y_datos.sql`: Creación del modelo relacional e inserción de datos de prueba.
* `02_consultas_analiticas.sql`: Consultas SQL para generación de reportes y métricas clave de negocio.
