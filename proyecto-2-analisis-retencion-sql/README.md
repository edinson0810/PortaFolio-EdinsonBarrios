# 📊 Proyecto 2: Análisis de Retención y Métricas de Clientes (SQL Avanzado)

## 📌 Descripción
Proyecto enfocado en el cálculo de métricas clave de negocio (**Lifetime Value**, frecuencia de compra e intervalos de retención) utilizando consultas avanzadas de SQL con **Window Functions** (`ROW_NUMBER`, `LAG`) y **CTEs**.

---

## 🛠️ Habilidades Demostradas
* **Funciones de Ventana:** Clasificación secuencial de eventos y diferencias temporales entre compras.
* **Expresiones de Tabla Comunes (CTEs):** Estructuración modular para análisis multietapa.
* **Métricas de Negocio:** Ticket promedio, volumen de compras y hábitos de recompra.
